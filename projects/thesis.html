📌 Overview

Autonomous Mobile Robots (AMRs) are increasingly used in industrial logistics due to their flexibility. However, coordinating multiple robots in shared environments remains a major challenge.

This thesis presents a centralized traffic management system that enables efficient coordination of multiple robots using a graph-based representation of the environment.

⚠️ Problem Statement

In real-world industrial environments, multiple robots operate simultaneously in shared spaces such as narrow corridors and intersections.

  • Collision risks between robots
  • Deadlocks in constrained environments
  • Inefficient waiting and delays
  • Limited coordination between robot fleets

🧠 Approach

The system models the environment as a topological graph, enabling structured decision-making for robot movement and coordination.

  • Graph-based environment modeling
  • Predefined traffic rules (left/right/center)
  • Centralized traffic controller
  • Real-time robot tracking

✨ Key Contributions

  • 🔍 Conflict detection between robot paths
  • 🔄 Dynamic detour generation to avoid collisions
  • ⏸️ Intelligent waiting strategy when detours are not possible
  • 📡 ROS2-based system integration
  • 🤖 Support for heterogeneous robot fleets

🏗️ System Architecture

The system consists of two primary layers:

  • Fleet Management System (FMS): Task allocation and coordination
  • Robot Layer: Navigation and execution

Communication is handled using ROS2 and MQTT-based protocols.
