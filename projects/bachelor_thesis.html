Deep Learning CNN Computer Vision Python Raspberry Pi

📌 Overview

This project focuses on detecting diseases in paddy crops using Convolutional Neural Networks (CNN). The system captures leaf images and classifies them into healthy or diseased categories, enabling early diagnosis and improving agricultural productivity.

Sample Input / Output (to be added)

⚠️ Problem Statement

Manual detection of crop diseases is time-consuming, error-prone, and requires domain expertise.

  • Late detection leads to crop loss
  • Dependence on human expertise
  • Difficulty in identifying diseases visually
  • Lack of automated monitoring systems

🧠 Approach

  • Dataset collection of paddy leaf images
  • Image preprocessing and augmentation
  • CNN model training for disease classification
  • Deployment on embedded system (Raspberry Pi)
  • Real-time image capture using Pi camera
