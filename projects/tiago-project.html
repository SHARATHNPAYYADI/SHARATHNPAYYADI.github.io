ROS MoveIt Computer Vision Gazebo Manipulation

📌 Overview

This project focuses on building a complete pick-and-place pipeline using the TIAGo robot. The system integrates perception, planning, and control to autonomously detect, grasp, and place objects in both simulation and real-world environments.

⚠️ Problem Statement

  • Accurate object detection and pose estimation
  • Collision-free motion planning
  • Coordination between perception and manipulation
  • Handling real-world execution uncertainties

🧠 Approach

  • Object detection using ArUco markers and OpenCV
  • Pose estimation using camera data
  • Motion planning using MoveIt
  • Octomap-based collision environment
  • Execution on both simulation and real robot

End-to-end pipeline illustrating perception, planning, and execution for autonomous pick-and-place using the TIAGo robot.

🏗️ System Architecture

  • Perception Layer: Camera + ArUco detection
  • Planning Layer: MoveIt motion planning
  • Execution Layer: Arm and gripper control
  • ROS Nodes: pick_and_place, move_group, tf

✨ Key Features

  • Autonomous object detection using RGB-D camera
  • Real-time motion planning with collision avoidance
  • ROS-based modular design
  • Simulation and real-world deployment
  • Dynamic environment mapping using Octomap

📊 Results

  • Successful pick-and-place in Gazebo simulation
  • Real-world execution on TIAGo robot
  • Stable and reliable motion planning
  • Accurate pose estimation using ArUco markers

🔮 Future Work

  • Improve object detection beyond markers
  • Integrate mobile base navigation
  • Use linear motion planning (MoveL)
  • Enhance obstacle-aware planning
  • Deploy using Docker for scalability
